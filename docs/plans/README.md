# Plan index

Design and decision records, ordered newest first. A plan's date, unchecked boxes, or
`artifact_readiness` field does not establish whether its work is still open.
[GitHub Issues](https://github.com/eddiefiggie/ddo-loadout-optimizer/issues) owns status;
the [development guide](../DEVELOPMENT.md) explains how to choose work.

design behind [roll-up #911](https://github.com/eddiefiggie/ddo-loadout-optimizer/issues/911).
Read its issue and current code before following an old phase checklist.

## Using historical plans

- Search by topic below, then read the corresponding issue and merged PRs.
- An old deferral is not a new task: check for a filed issue, later implementation,
  a documented ruling, or an explicit non-goal before reviving it.
- Keep existing filenames and links stable. Add new plans here when introduced.
- Do not mass-mark plans complete from their age or metadata. This index catalogs
  the files; it does not certify the status of every historical checkbox.
